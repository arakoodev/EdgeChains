# Google Palm2 Chat Example

This example uses the `Palm2` class from `@arakoodev/edgechains.js/ai` to talk to the
[Google Generative AI (PaLM 2)](https://developers.generativeai.google/) chat endpoint.
All prompts and generation parameters live in the jsonnet files, nothing is hardcoded in TypeScript.

## Installation

1. Install the required dependencies:

    ```bash
    npm install
    ```

## Configuration

1. Add your PaLM 2 (Google Generative AI) API key in `jsonnet/secrets.jsonnet`:

    ```bash
    local PALM2_API_KEY = "your-palm2-api-key";
    ```

2. Edit the prompt template and generation parameters (`temperature`, `maxOutputTokens`,
   `candidateCount`, `topK`, `topP`) in `jsonnet/main.jsonnet`.

## Usage

1. Run with the default question:

    ```bash
    npm start
    ```

2. Or ask your own question (it is injected into the jsonnet prompt template):

    ```bash
    npm start -- "What is the capital of France?"
    ```

The answer generated by Palm2 is printed to the console.
