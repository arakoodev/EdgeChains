# PaLM 2 / Google Generative Language Chat Example (Jsonnet)

This example demonstrates calling Google's Generative Language API (`Palm2AI`) in EdgeChains with all prompt templates and generation parameters loaded dynamically from `jsonnet/main.jsonnet`.

## Running

```bash
export PALM2_API_KEY="your-google-api-key"
export TOPIC="declarative AI workflows"
npm install
npm run start
```
