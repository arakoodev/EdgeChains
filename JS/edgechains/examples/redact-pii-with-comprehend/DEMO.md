# Loom demo checklist

1. Show the example source, especially the `redactChatOptionsOperator()` pipeline.
2. Set AWS credentials outside the recording and keep them hidden.
3. Run `npm start` with a prompt containing an email or phone number.
4. Show the redacted prompt/result reaching the endpoint, with no raw PII in logs.
5. Open the pull request and attach the Loom URL before requesting review.
